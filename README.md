# 鳳新高中備考專屬 APP

海軍藍 × 暖白的繁體中文單機學習 APP。沒有框架、CDN 或安裝依賴；下載 **index.html**，用瀏覽器開啟即可。內建 30 題原創高中英文與數學選擇題；這是練習工具，非鳳新高中官方題庫，請依老師公告設定實際範圍。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 包含 CSS、JavaScript、30 題題庫的完整單檔 APP |
| `鳳新高中各科題庫.csv` | UTF-8 BOM 的 Google 試算表匯入範本／初始 30 題 |
| `Code.gs` | 綁定 Google Sheets 的每日 AI 出題腳本 |
| `questions.json` | 同一份初始題庫，供檢閱與驗證；APP 不需載入此檔 |
| `tests/smoke.cjs` | Chromium 瀏覽器功能測試 |
| `tests/gas.cjs` | GAS 模擬環境測試（不呼叫付費 API） |

## 開始使用

1. 下載 `index.html` 後直接開啟。若手機的檔案預覽器不允許 JavaScript，請改用能執行本機 HTML 的瀏覽器，或將檔案放在可信任的 HTTPS 靜態網站上。
2. 在「設定」選擇段考／模考、第一次段考／第二次段考／期末考／學測模擬考、考試日期、考科、各科目標與目前預估分數、每日分鐘數與每週讀書日，按「儲存設定並更新計畫」。
3. 「讀書計畫」排到考前一天，以分數差距分配每天的時間，勾選完成。範圍備註是提醒；自動輪替的單元來自目前題庫，請依實際範圍調整題庫。已過期或當日考試不會安排考前任務。
4. 「今日模擬考」選擇 1–50 題與考科，隨機抽題且不重複；不足時使用所有可用題。提交後顯示正確率、每題答案及解析；未答算錯。
5. 「錯題本」保留錯題快照與答錯次數。針對錯題重測最多抽 50 題；重測答對會移出清單，仍答錯的保留。普通測驗答對不自動清除錯題。
6. 「題庫」可依考科、難度、關鍵字瀏覽；CSV 更新採合併方式，同 ID 更新內容、不刪除其他題目。舊錯題仍保留當時題目內容，避免新題覆蓋作答紀錄。

設定、題庫、已完成任務、最近 500 次測驗統計與錯題使用 `localStorage`，只屬於目前瀏覽器／來源。直接開本機檔案時，瀏覽器可能依檔案路徑分開儲存；移動檔案、無痕模式、清除網站資料或換瀏覽器可能失去紀錄。請用「下載目前題庫 CSV」備份題庫（不包含學習紀錄）。儲存失敗會提示，仍可在本次頁面使用。未提交測驗與 API Key 在重新整理後不保留。

內建題只有英文與數學；選擇國文、自然、社會後仍可安排課本複習，但需匯入對應題目才能測驗。分數使用 0–100 規劃尺度，不代表學測級分換算或成績預測。

## Google Sheets 題庫

目前提供 CSV，沒有直接建立你的 Google Drive 檔案。

### 建立與匯入

1. 在 Google Drive 新增 Google 試算表，檔名設為 **鳳新高中各科題庫**。
2. 選「檔案 → 匯入 → 上傳」，上傳 `鳳新高中各科題庫.csv`。可選「取代目前工作表」（請先確認工作表無需保留的資料），分隔符號選逗號或自動偵測。
3. 將匯入的工作表分頁改名為 **題庫**，供 `Code.gs` 的預設設定使用。
4. 確認第一列欄位名稱與順序如下（共 11 欄，不能少欄或多欄）：

```csv
題目 ID,考科,範圍/單元,難易度,題目內容,選項 A,選項 B,選項 C,選項 D,正確答案,詳細解析
```

考科接受「國文、英文、數學、自然、社會」；難度接受「基礎、段考進階題」；答案使用 A／B／C／D。ID 必須唯一；題目、單元、選項、解析不得為空；四個選項不得完全相同或重複。若儲存 CSV，含逗號、引號或換行的欄位要以雙引號包住，欄內雙引號寫成兩個雙引號。單次匯入上限 1,000 題／2 MB，本機合併上限 5,000 題。

### 發布到網路為 CSV

1. 在試算表選「檔案 → 共用 → 發布到網路」（介面版本可能顯示於「檔案 → 發布到網路」）。
2. 在「連結」分頁，第一個下拉選 **題庫** 工作表，第二個下拉選 **逗號分隔值（.csv）**。
3. 按「發布」並確認。若有「已發布的內容和設定」，啟用變更時自動重新發布。
4. 複製 Google 提供的發布網址，通常像：

```text
https://docs.google.com/spreadsheets/d/e/發布識別碼/pub?gid=工作表編號&single=true&output=csv
```

5. 在 APP「設定」貼入 CSV 連結並儲存，再到「題庫」按「從 CSV 連結更新」。APP 不會自動輪詢，GAS 新增題目後需手動更新；Google 發布快取可能延遲數分鐘。

發布網址與一般的試算表編輯／共用網址不同。發布後內容可公開讀取，僅發布題庫工作表，不要放個資或 API Key。若學校帳號管理員禁止公開發布，請用「檔案 → 下載 → 逗號分隔值」下載目前題庫，在 APP 匯入檔案；不必變更帳號政策。

Fetch 需要網路，也受 Google 發布權限、瀏覽器 CORS／本機 `file://` 安全政策限制。APP 會保留原題庫並提示失敗；直接下載 CSV 後匯入是離線替代方式。不使用公開代理轉送題庫或 API Key。

## APP 內的 AI 出題

在設定填入自己的 **OpenAI API Key** 與可用的模型名稱（預設 `gpt-4o-mini`），儲存後到題庫選考科、難度和實際範圍，按「用 AI 產生 5 題」。每次呼叫前會確認可能計費；API 只接收出題範圍、考科與難度，不傳送你的分數或錯題紀錄。回傳資料先完成欄位驗證才合併入題庫。請人工核對 AI 的答案與解析；格式正確不等於答案正確。

Key 僅在頁面記憶體／密碼輸入欄存放，不存到瀏覽器磁碟、不匯出、不寫入 HTML。任何能使用這個頁面的人及瀏覽器擴充套件仍可能讀取本次輸入，所以不要在共用電腦使用，不要發布預填金鑰的 HTML。瀏覽器直接呼叫固定的 OpenAI HTTPS API，金鑰只能由自己輸入；若連線受限，可使用下方 GAS 流程。不需要金鑰也能使用內建題庫與全部離線功能。

## Google Apps Script：每天約早上 6 點新增 5 題

### 綁定與設定

1. 開啟 **鳳新高中各科題庫**，選「擴充功能 → Apps Script」。
2. 將 `Code.gs` 的完整內容貼入 `Code.gs`，儲存。
3. 到 Apps Script「專案設定」，將專案時區設為 **Asia/Taipei**。
4. 在「指令碼屬性」新增：

| 屬性名稱 | 值 |
| --- | --- |
| `AI_API_KEY` | 你的 OpenAI API Key（只在此設定，不貼到聊天或試算表） |
| `EXAM_SCOPES_JSON` | `{"英文":"現在完成式、關係代名詞","數學":"二次函數、機率"}`；請改成老師公告範圍 |
| `AI_MODEL` | 選用；預設 `gpt-4o-mini`，可填帳號有權使用且支援 JSON 模式的模型 |
| `SHEET_NAME` | 選用；預設 `題庫`，須與匯入 CSV 的分頁名稱一致 |

5. 執行 `setupQuestionSheet`，授權讀寫此試算表。此函式只建立不存在的題庫分頁、初始化空白表頭或驗證既有表頭，不會清除內容。
6. 手動執行一次 `dailyGenerateQuestions`，授權對外 API 請求。這會呼叫付費 API 並新增 5 題，請確認試算表新增列與解析。每天從設定的考科中隨機挑一科，生成該科 5 題「段考進階題」。不會自動知道鳳新高中的最新考試範圍。
7. 執行 `installDailyTrigger`，安裝每日排程。會只替換目前使用者所建立、處理函式為 `dailyGenerateQuestions` 的觸發器，保留其他觸發器。

**Apps Script 無法保證整點執行。** 程式設定為台灣時間 06:00 附近（`atHour(6).nearMinute(0)` 通常前後約 15 分鐘）；實際時間可能因 Google 排程延遲。

### 手動設定 Time-driven Trigger

若不使用 `installDailyTrigger`：左側「觸發條件」（時鐘圖示）→「新增觸發條件」→ 函式 `dailyGenerateQuestions` → 部署 `Head` → 事件來源「時間驅動」→ 類型「日計時器」→「上午 6 點至 7 點」→ 儲存並授權。手動介面採一小時時間窗，並非精確 06:00。**自動安裝與手動安裝擇一**；請由一位負責人管理觸發器。

### 失敗與重複執行

- 每次先取得 Script Lock，完整驗證 5 題才一次寫入 5 列 × 11 欄；API 錯誤、JSON 無效、題數不符、空白欄位、重複選項等不會寫入。
- 每日批次 ID 為 `GAS-yyyyMMdd-UUID-題號`。若當天已存在 5 題，重跑會略過；若發現當天不完整或多於 5 列，會停止並要求檢查，不自動刪除資料。使用資料列判斷可避免「寫入成功但屬性更新失敗」造成重複呼叫。
- 只記錄成功／HTTP 狀態等摘要，不輸出 API Key；以 `=` 等開頭的 AI 文字會作為純文字寫入，避免執行試算表公式。
- 查看 Apps Script「執行項目」中的錯誤紀錄，並為觸發器設定失敗通知。401 檢查金鑰、429 檢查 API 額度／速率；模型存取或服務失敗修正後可再手動執行。Google 執行時間／每日配額仍適用。
- AI 出題需要你的 Google 授權、API Key、API 可用額度與實際範圍；本儲存庫不包含憑證，也尚未部署或驗證你的 Google 帳號內的觸發器。

## 開發與驗證

可直接開 HTML，也可在既有 checkout 啟動本機靜態伺服器：

```sh
cd /workspace/high-school-exam
python3 -m http.server 8000 --bind 127.0.0.1
```

不需建立 Git worktree。HTTP 與本機檔案的瀏覽器儲存來源不同。程式無 build／npm install 步驟。

已提供不呼叫付費 API 的測試；瀏覽器測試需要 Node.js、Playwright 與 Chromium（若在其他機器使用，請先安裝這些測試工具）。

```sh
node tests/smoke.cjs
node tests/gas.cjs
```

瀏覽器測試先嘗試本機 `file://`；若受託管 Chromium 的管理政策阻擋，改用測試內建的本機 HTTP 伺服器載入同一個單檔，檢查設定、精確分鐘分配、錯題與重測、重整後保留資料、CSV 引號／換行與錯誤格式、AI 成功與失敗（模擬回應）、手機版面及文字注入。GAS 測試採 API／試算表替身，驗證五題追加、每日防重、拒絕無效回應、HTTP 失敗與觸發器設定；不等同於實際 Google 或 OpenAI 部署驗證。
